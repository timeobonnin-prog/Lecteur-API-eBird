Lecteur API eBird

Une interface cartographique libre pour visualiser les observations d'oiseaux en temps réel. Connectez-vous avec votre clé eBird, explorez la biodiversité autour de vous et exportez vos données.

Lancer l'application

Fonctionnalités principales

🗺️ Carte interactive

Naviguez librement, centrez sur votre position et choisissez parmi 4 fonds de carte (sombre, clair, satellite, topographique).

🐦 Recherche par espèce

Tapez le nom d'un oiseau et obtenez instantanément les checklists à proximité grâce à l'autocomplétion et à la taxonomie eBird.

📍 Recherche de lieu

Trouvez n'importe quel endroit dans le monde avec l'autocomplétion géographique et explorez les observations locales.

📤 Export de données

Téléchargez vos observations en CSV, TXT ou JSON avec toutes les colonnes du standard eBird, prêtes à être analysées.

🔒 Sécurité & vie privée

Votre clé API n'est jamais stockée sur un serveur. Validation CAPTCHA à l'entrée et chiffrement local des préférences.

📱 Adapté mobile

L'interface s'adapte parfaitement aux petits écrans avec un panneau d'observation escamotable.

Comment utiliser le lecteur ?

  1. Obtenez une clé API eBird gratuite (inscription rapide).
  2. Accédez à l'application et collez votre clé dans le champ prévu.
  3. Résolvez le CAPTCHA pour prouver que vous n'êtes pas un robot.
  4. Cliquez sur la carte ou utilisez la recherche de lieu pour définir votre zone d'intérêt.
  5. Parcourez les checklists, filtrez par espèce et exportez vos trouvailles !
